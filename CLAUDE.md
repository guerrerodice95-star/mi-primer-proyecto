# Instrucciones para Claude

Este repositorio guarda los proyectos de edición de video de TheCryptons (@TheCryptons_), en la carpeta `edicion/`.

Cuando el usuario pida editar un video:

1. Lee `edicion/GUIA-DE-ESTILO.md` (sus gustos: encuadre, efectos, sonido, subtítulos) y `edicion/COMO-EDITAR.md` (parte técnica).
2. Crea la carpeta del video en `edicion/verticales/` o `edicion/horizontales/` partiendo del proyecto más parecido.
3. Si el usuario corrige algo que sirva para futuros videos, añádelo a la guía de estilo.
4. Al terminar, guarda el proyecto en GitHub (sin los videos: van en Drive).

Responde en español.
